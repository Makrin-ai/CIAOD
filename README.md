# Data Structures and Algorithms (CIAOD)

This repository contains a collection of academic projects and laboratory works completed during the **"Data Structures and Algorithms"** course. This subject is a core part of the IT curriculum, typically studied by 1st and 2nd-year students.

The main goal of these projects is to develop a deep understanding of how data is organized, stored, and processed efficiently.

## 📚 Course Overview

The projects in this repository cover the following key topics:

*   **Data Structures:** Implementation and usage of linear and non-linear structures, including arrays, lists, stacks, queues, trees, and graphs.
*   **Algorithms:** Practical application of various algorithms, such as sorting methods, searching algorithms, and graph/tree traversal techniques.
*   **Complexity Analysis:** Evaluating the efficiency of algorithms in terms of time and memory consumption.

## 📂 Repository Structure

The repository is organized by laboratory works and practical assignments:

*   `work5_1`, `work5_2` — Laboratory works on basic algorithms and data structures.
*   `work6_1`, `work6_2` — Laboratory works on advanced data structures.
*   `work7_1`, `work7_2` — Laboratory works on sorting and searching algorithms.
*   `work8_1`, `work8_2` — Final laboratory works covering complex algorithms.

### 🏢 Additional Projects

*   **Realty Accounting System (BTI):** Inside the repository, you can find a Kotlin console application for managing real estate records. It demonstrates practical application of CRUD operations, file I/O (JSON), and data sorting/filtering.
